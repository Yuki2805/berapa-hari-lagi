# Berapa Hari Lagi Counter ⏳

Aplikasi web interaktif untuk menghitung mundur waktu menuju acara tertentu. Proyek ini dibangun menggunakan HTML, CSS, dan JavaScript murni.

## Fitur Utama
- Penghitung waktu mundur secara real-time.
- Penyimpanan data acara menggunakan Local Storage agar tidak hilang saat peramban ditutup.
- Antarmuka pengguna dengan efek Glassmorphism.
- Indikator progress bar visual.
- Animasi konfeti saat target waktu telah tercapai.
- Tampilan responsif.

## Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript

## Cara Menjalankan
1. Unduh atau clone repositori ini.
2. Buka file \index.html\ menggunakan peramban web.
3. Masukkan nama acara dan target tanggal untuk memulai hitung mundur.
